# Support

## Supported object

The citable software object is the immutable TEA-Sim TrustEvidence v2.2.0 release:

- exact-version DOI: <https://doi.org/10.5281/zenodo.21533962>
- GitHub release: <https://github.com/antonioclim/TEA-Sim-TrustEvidence/releases/tag/v2.2.0>

Later commits on `main` may improve metadata or documentation. They are not replacement releases unless a new version and DOI are published.

## Routine questions and reproducibility defects

Open a GitHub issue for:

- installation failures in a documented environment;
- a mismatch between retained results and a public checker;
- unclear documentation;
- a proposed reuse or extension;
- a minimal reproducible software defect.

Include:

- operating system and architecture;
- Python version;
- exact tag or commit;
- command executed;
- complete error text;
- the smallest non-sensitive fixture that reproduces the problem.

Do not attach credentials, tokens, private keys, patient data, restricted datasets or unpublished third-party material.

## Scope boundary

Support covers the research software and its declared synthetic corpora. It does not provide:

- production EHR integration;
- clinical support;
- legal or compliance advice;
- hospital service-level commitments;
- identity-provider, HSM/KMS or durable-log operations;
- warranty of fitness for a regulated use.

## Security-sensitive reports

Do not disclose a suspected vulnerability in a public issue. Follow `SECURITY.md`.
